# RQ2: FedARM and baseline comparison

`run_fedarm.py` runs the proposed FedARM method. The baseline implementations
are shared code under `code/baseline/`; their RQ2 execution entry points are
`code/baseline/run_gpu_baselines.py` and
`code/baseline/run_reproduced_baselines.py`.

Run all three entry points from the repository root. The detailed commands,
densities, seeds, data preparation, and output conventions are documented in
the root `README.md`.
